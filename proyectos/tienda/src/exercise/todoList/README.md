# TodoList en Typescript


## Especificaciones

Se desea crear un TodoList para gestionar las tareas en typescript
Se debe tener en cuenta lo siguiente

- Prohibido usar push, slice, splice, sort
- Las tareas tienen las prioridades; low, medium, high
- De una tarea necesitamos el id, title, priority y un check para saber si esta completada o no: done

### Metodos a ejemplificar

- createTask
- toggleDone
- rename
- removeDone
- editTask
- pendingByPriority

Crear por tanto un main.ts en la carpeta todoList que permita ejemplificar una app de tareas
